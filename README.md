# week-4-supervised-learning
Supervised Machine Learning project using Python and Scikit-learn to classify breast cancer samples as benign or malignant using Logistic Regression, with data preprocessing, model evaluation, cross-validation, and visualizations.
# Week 4: Supervised Learning Model Implementation

## Breast Cancer Classification Using Logistic Regression

### Project Overview
This project implements a supervised machine learning classification model using Python and the Breast Cancer Wisconsin dataset. The objective is to classify samples into two categories: benign and malignant.

### Objectives
- Understand and prepare a public dataset.
- Perform data cleaning and preprocessing.
- Select input features and define the target variable.
- Split the dataset into training and testing sets.
- Implement Logistic Regression using Scikit-learn.
- Evaluate model performance using classification metrics and cross-validation.
- Visualize the results using graphs.

### Dataset
- **Dataset:** Breast Cancer Wisconsin Original Dataset
- **Task:** Binary classification
- **Target classes:** Benign and Malignant
- **Source:** UCI Machine Learning Repository

### Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

### Model
Logistic Regression is used as the supervised classification algorithm. The project includes feature preprocessing, train-test splitting, model training, and evaluation.

### Evaluation Metrics
The model is evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix
- Stratified 5-Fold Cross-Validation

### Visualizations
The project includes visualizations for class distribution, feature correlation, confusion matrix, and ROC curve, where available in the submitted files.

### Project Files
- `Week_4_Supervised_Learning_Nandita_Manna.ipynb` — Google Colab notebook containing the Python implementation.
- `Week_4_Supervised_Learning_Nandita_Manna.docx` — Project report documenting the methodology and results.

### How to Run
1. Open the `.ipynb` file in Google Colab.
2. Upload or load the dataset as required by the notebook.
3. Run the notebook cells in order.
4. Review the evaluation metrics and generated visualizations.

### Conclusion
This project demonstrates a supervised machine learning workflow for binary classification using Logistic Regression. Multiple evaluation metrics are used to assess model performance.
